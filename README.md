# Gyan — Android app downloads

This repository only hosts the installable app file and the download page.
It does not contain the app's source code.

**Download page:** https://gyandeepmittal.github.io/gyan-app/

**Direct link to the newest APK (never changes):**
https://github.com/gyandeepmittal/gyan-app/releases/latest/download/gyan.apk

## Install on Android

1. Open the download page on your phone and tap **Download Gyan for Android**.
2. Open the downloaded file. If asked, allow installs from this source.
3. If Play Protect warns you, tap **More details → Install anyway**.
4. Open Gyan, sign up with your email, and enter your invite code.

Gyan is shared by invitation only. iPhone is not supported yet.
